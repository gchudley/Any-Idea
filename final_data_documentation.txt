Data Documentation for nyc_2024_data_selected.csv

This csv file has 62 data columns including the property_id, which is used as an identifier.

Data Field Description (in the csv file order)
----------------------------------------------------------------------------------------------------

property_id: Unique ENERGY STAR Portfolio Manager property identifier for the reported property.

    Type: Identifier
    Unit: None
    Example: 7365


primary_property_type_self: Primary property use selected by the reporting user, rather than calculated by Portfolio Manager.

    Type: Categorical
    Unit: None
    Example: ["Office", "Financial Office", "Hospital (General Medical & Surgical)", "Retail Store", "Laboratory"]


national_median_reference: Property category used to select the national-median comparison benchmark.

    Type: Categorical
    Unit: None
    Example: ["CBECS - Office & Bank/Financial", "ASHE Survey", "CBECS - Retail Store", "CBECS - Laboratory", "CBECS - Other"]


list_of_all_property_use: A text list of the property's use types and their corresponding gross floor areas, in ft².

    Type: Text
    Unit: None
    Example: ["Office (668602.0), Financial Office (11116.0), Food Service (9494.0), Bank Branch (0.0), Retail
        Store (4840.0)", "Restaurant (3262.0), Office (337187.0), Financial Office (16383.0), Bank Branch
        (3023.0), Retail Store (23310.0)", "Other - Entertainment/Public Assembly (32668.0), Restaurant
        (18515.0), Office (149601.0), Financial Office (368732.0)", "Restaurant (34269.0), Office (348996.0),
        Retail Store (6021.0)", "Office (1020704.0), Financial Office (480712.0), Food Service (18924.0),
        Retail Store (61047.0)"]

    Type: Continuous
    Unit: Square feet (ft2)
    Example: [668602.0, 337187.0, 368732.0, 348996.0, 1020704.0]
